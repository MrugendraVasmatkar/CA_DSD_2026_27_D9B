# CA1 — Design and Architecture Submission

Submit the design work for the problem statement allotted to your group. The problem statement itself has already been provided; do not replace it with a different problem.

## What to submit

1. **Problem understanding**
   - Brief explanation of the assigned problem.
   - Functional requirements and assumptions.
   - Inputs, outputs and their purpose.

2. **System architecture**
   - Overall block diagram.
   - Description of the main functional blocks and their interaction.

3. **FSM design** (where applicable)
   - State diagram.
   - State/transition table.
   - Brief explanation of states and transitions.

4. **Datapath design** (where applicable)
   - Datapath block diagram.
   - Registers, counters, arithmetic and comparison units.
   - Control signals and their functions.
   - Explanation of controller–datapath interaction.

5. **Logisim design and verification**
   - Logisim circuit file.
   - Screenshot of the complete circuit.
   - Screenshots/evidence for important test cases.
   - Expected and observed outputs.

6. **Design explanation**
   - Short explanation of the design approach.
   - Any design choices or alternatives and the reason for the selected approach.

## Suggested contents inside `CA1`

- `Problem_Analysis/`
- `Architecture/`
- `FSM/`
- `Datapath/`
- `Logisim/`
- `Test_Cases/`

## CA1 checklist

- [ ] Requirements, assumptions, inputs and outputs are documented.
- [ ] Architecture diagram is clear and labelled.
- [ ] FSM diagram and state table are included, where applicable.
- [ ] Datapath and control signals are explained, where applicable.
- [ ] Logisim file and screenshots are uploaded.
- [ ] Test cases include expected and observed outputs.
