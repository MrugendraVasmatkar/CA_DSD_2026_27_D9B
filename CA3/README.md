# CA3 — FPGA Implementation and Final Demonstration Submission

Submit the FPGA implementation and final demonstration evidence for your group's assigned design.

## What to submit

1. **FPGA project files**
   - Project/source files required to open the design in the selected FPGA tool.
   - Top-level module and constraints file (for example, XDC for a Xilinx device).
   - Pin assignments and clock constraints, as applicable.
   - FPGA board/device details and tool version.

2. **Implementation evidence**
   - Synthesis and implementation completion evidence.
   - Resource utilization results (such as LUTs, flip-flops and other relevant resources).
   - Timing summary/report, where applicable.
   - Bitstream generation evidence.

3. **Hardware demonstration**
   - Photographs/screenshots of the FPGA board setup.
   - Evidence showing applied inputs and corresponding outputs.
   - Short demonstration video or link, if requested by the faculty.
   - Explanation of the mapping between board switches/buttons/LEDs and design signals.

4. **Final verification and results**
   - Hardware test cases.
   - Expected and observed outputs.
   - Comparison of simulation and hardware behaviour.
   - Issues encountered and corrective actions.

5. **Final documentation**
   - Final block/architecture diagram.
   - Summary of the design and implementation.
   - Results, observations and conclusion.
   - Presentation slides, if requested.

## Suggested contents inside `CA3`

- `FPGA_Project/`
- `Constraints/`
- `Implementation_Reports/`
- `Hardware_Demo/`
- `Results/`
- `Final_Documentation/`

## CA3 checklist

- [ ] FPGA board/device and tool version are stated.
- [ ] Project source and constraints are included.
- [ ] Synthesis/implementation results are documented.
- [ ] Hardware demonstration evidence is included.
- [ ] Hardware test cases and observations are documented.
- [ ] Final report/presentation is included if requested.
